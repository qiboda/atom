# 程序化游戏项目 — 方向

## 核心原则

**算法驱动一切。** 地形、生态、材质、遭遇、叙事——全部由系统生成。手工内容仅存在于系统参数的初始设定。目标不是「做一个游戏」，而是「做一个生成游戏的系统」。

## 设计结论（来自游戏研究）

- 高强度战斗 → 快速疲劳。探索 + 轻度遭遇 → 更长游玩时间
- 地形多样性决定长期兴趣——「没探索过的地形」是核心驱动力
- 跑路痛苦源于重复路线，自由移动 + 传送点解决
- 玩家需要自主决策感，不是被推着走

## 最小产品方向

一个**可探索的程序化世界**：玩家在算法生成的自然地形中自由移动，遇到算法生成的遭遇。每一局的地形、生态、资源分布不同。

技术核心是地形生成管线——其他系统（技能、怪物、叙事）都是地形之上的数据层。

## 技术累积栈（按优先级）

1. **地形** — 密度场 + Dual Contouring + biome 驱动形状
2. **材质** — biome 驱动的顶点纹理混合
3. **LOD** — 远距离替代几何，支撑更大可视范围
4. **寻路** — nav mesh，玩家周围 300m 动态生成
5. **技能系统** — 已部分实现（atom_ability），待与地形交互
6. **怪物 AI** — 基于 biome 和地形的生成规则
7. **CSG 编辑** — 仅用于系统生成洞穴/构造物，不只用于玩家编辑
